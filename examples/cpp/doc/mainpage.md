# Greeter detail design

Detail design of the Greeter example, generated by doxygen from the comments in
the `src` folder.

- The classes, their members and the call graphs are listed in the *Classes*
  and *Files* sections.
- The *Requirement Traceability* page lists the requirements each function
  implements (`@implements` tags). trlcdoc extracts the same tags for the
  tracing report.
